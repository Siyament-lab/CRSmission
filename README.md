# CRSmission
Inlämningsuppgift för kassasystemet som är döpt till CRSmission.
Huvudmenyn --: CRSHomeMenu.cs
Produktlista --: Products.cs
Innehåll: Utöver produktlista innehåller denna klass kundvagnsfunktioner och hjälpattribut klass.
Nykundmenyn --: SalesMenu.cs
Innehåll: Menylista för olika alt, sparande av kvitton
Kundvagn/försäljning --: Sales.cs
Innehåll: Funktioner för att lägga till produkter, beräkna total och visa tilllagda produkter.
Kvittohantering --: ReceiptStorage
Innehåll: Sparande av kvitton, ompositionering av kvitto mappen samt utformning av kvitto.

Fr main (program.cs) anropas huvudmenyn och salesMenu klasser, kör igång programmet.
Det mest kod-tyngda klasserna är Products och SaleMenu.

OBS: Vissa funktioner som tillhör VG-nivå är ej berarbetade, men dessa påverkar inte funktionalliteten
uppgiften för G-krav.
